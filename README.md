# Calculus Final Exam Table

> Projeto de estudo sobre o elemento `<table>` do HTML e organização semântica de páginas.

---

## 📖 Descrição

Este projeto reproduz uma tabela de prova final de Cálculo usando apenas HTML. O objetivo é praticar a criação de tabelas com o elemento `<table>`, que hoje é menos usado para layout, mas continua sendo a forma correta de apresentar dados tabulares, e aplicar boas práticas de HTML semântico.

Este repositório é de **estudo e demonstração pública**: faz parte dos meus estudos de desenvolvimento web e é um dos projetos de aprendizado que mantenho aqui no GitHub. Projetos maiores serão adicionados no futuro.

## ✨ Funcionalidades e Componentes

- Tabela estruturada com cabeçalho, corpo e rodapé
- Células de cabeçalho (`<th>`) separadas das células de dados (`<td>`)
- Legenda descritiva para a tabela (`<caption>`)
- Mesclagem de células com `colspan` e `rowspan`, quando necessário
- Página organizada com elementos semânticos

## 🔑 Key Concepts

| Elemento | Função |
|---|---|
| `<table>` | Container principal da tabela |
| `<caption>` | Título da tabela |
| `<thead>` | Agrupa o cabeçalho |
| `<tbody>` | Agrupa o corpo de dados |
| `<tfoot>` | Agrupa o rodapé |
| `<tr>` | Linha da tabela |
| `<th>` | Célula de cabeçalho |
| `<td>` | Célula de dados |
| `colspan` / `rowspan` | Mesclagem de colunas e linhas |
